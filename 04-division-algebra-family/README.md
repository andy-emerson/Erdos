# A family over the division algebras

Research only: this folder has no spec text. The family (one-byte headers for the reals, complex numbers, quaternions and octonions, over fixed-width words) was researched as the successor to [Q v0.3](../03-q/v0.3.md), and is superseded by planned separate specifications for exact rationals and for hypercomplex units, not yet written.

- [`research/`](research/): the research notes ([family](research/division-algebra-family.md), [phase one](research/phase1-variants.md), [threshold, storage and libraries](research/threshold-storage-libraries.md)) and [prior art](research/prior-art-family.md).
- [`test/`](test/): the code, tests and raw results, with [how to run them](test/README.md).
