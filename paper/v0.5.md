## 1. Naive rational arithmetic

A rational number is a fraction $p/q$ of two whole numbers with $q \neq 0$. This section covers how a program usually stores one and how it adds, subtracts, multiplies and divides two of them. Three things are kept apart throughout:

- **arithmetic:** the identities about fractions that make a step correct;
- **structure:** how the two whole numbers sit in memory;
- **algorithm:** the steps a program runs.

"Naive" means the textbook formulas, applied directly. The only extra cleverness allowed is a *shortcut*: before running the formula, the program checks whether some of the stored numbers are equal (or zero). When they are, an identity gives the same answer with fewer multiplications, or none, because equal factors cancel exactly.

**Structure: how a rational is stored.** In programming, a rational is usually stored as two whole numbers, a numerator and a denominator, with one of them carrying the sign. The most common layout is two signed integers of the same width, with the denominator kept positive. The running example in this paper is a signed 32-bit numerator next to a signed 32-bit denominator:

| Field | Type | Holds |
|---|---|---|
| numerator | signed 32-bit integer | any whole number; carries the sign of the value |
| denominator | signed 32-bit integer | always positive |

Other layouts and widths exist: 16-, 32- or 64-bit fields, a signed numerator over an unsigned denominator, or two unsigned magnitudes plus a separate sign. Each has trade-offs, and the rest of this paper does not depend on them. In the running layout, the sign lives in the numerator, so the denominator is always positive and never zero, and dividing by zero is an error. Zero itself is stored as numerator $0$ over any positive denominator.

**Notation.** In formulas, the two inputs are $a/b$ and $c/d$, with $b > 0$ and $d > 0$. In pseudocode, `a / b` names a stored pair, numerator `a` and denominator `b`; it is *not* a division. Every `+`, `−` and `·` in pseudocode is ordinary integer arithmetic on the stored numbers, and `return n / m` returns the pair with numerator `n` and denominator `m`. In conditions, `=`, `<` and `>` compare two whole numbers; they never assign.

### 1.1 Addition and subtraction

**Arithmetic.** To add two fractions, bring them over a common denominator:

$$
\frac{a}{b} + \frac{c}{d} = \frac{a \cdot d + c \cdot b}{b \cdot d}.
$$

Subtraction is the same operation with the second numerator negated:

$$
\frac{a}{b} - \frac{c}{d} = \frac{a}{b} + \frac{-c}{d}.
$$

Negating a numerator is not a multiplication, and the denominator $d$ stays positive, so the result is still a valid stored value. From here on, everything about addition applies to subtraction too.

**Naive algorithm.** Three multiplications and one addition:

```text
function add(a / b, c / d)
    let n = a · d + c · b
    let m = b · d
    return n / m
end function

function subtract(a / b, c / d)
    return add(a / b, (−c) / d)
end function
```

**The major shortcut: a shared denominator.** If the two denominators are equal, $b = d$, the fractions already have a common denominator, and the numerators simply add:

$$
\frac{a}{d} + \frac{c}{d} = \frac{a + c}{d}.
$$

This is exact, because two equal denominators already are a common denominator. The cost drops from three multiplications and one addition to one addition and no multiplications at all. The denominator does not change: the result's denominator is the stored $d$, copied as is.

Signs need no special care. They live in the numerators, and $a + c$ is ordinary signed addition. For subtraction, $c$ has already been negated before `add` runs, so $\frac{a}{d} - \frac{c}{d}$ becomes $\frac{a + (-c)}{d} = \frac{a - c}{d}$.

*Worked example.* $\dfrac{1}{5} + \dfrac{2}{5}$. The denominators match ($5 = 5$), so the result is
$$
\frac{1 + 2}{5} = \frac{3}{5}.
$$
The naive path would need three multiplications and an addition; the shortcut needed one addition.

**Other shortcuts.** A few minor shortcuts also exist. If one term is zero, the answer is the other term. If the numerators are equal, $c = a$, the common factor $a$ can be pulled out:
$$
\frac{a}{b} + \frac{a}{d} = \frac{a \cdot d + a \cdot b}{b \cdot d} = \frac{a \cdot (b + d)}{b \cdot d},
$$
which needs two multiplications instead of three. Subtraction turns equal numerators into opposite ones, $c = -a$, and the same idea gives
$$
\frac{a}{b} + \frac{-a}{d} = \frac{a \cdot d - a \cdot b}{b \cdot d} = \frac{a \cdot (d - b)}{b \cdot d}.
$$
So $\frac{a}{b} - \frac{a}{d}$ lands on the second form and $\frac{a}{b} - \frac{-a}{d}$ on the first, without any separate rule for subtraction.

**All shortcuts for addition.** Inputs $a/b$ and $c/d$; for subtraction, $c$ is already negated.

| Shortcut | Condition | Result | Saved |
|---|---|---|---|
| Shared denominator (major) | $b = d$ | $\dfrac{a + c}{b}$ | all three multiplications; denominator unchanged |
| Zero term | $a = 0$ | $\dfrac{c}{d}$ | all three multiplications and the addition |
| Zero term | $c = 0$ | $\dfrac{a}{b}$ | all three multiplications and the addition |
| Shared numerator | $c = a$ | $\dfrac{a \cdot (b + d)}{b \cdot d}$ | one multiplication |
| Opposite numerators | $c = -a$ | $\dfrac{a \cdot (d - b)}{b \cdot d}$ | one multiplication |
| None (naive) | always | $\dfrac{a \cdot d + c \cdot b}{b \cdot d}$ | nothing |

**Algorithm with shortcuts.** The checks run in order: the major shortcut, then the minor ones from largest saving to smallest, then the naive path, which always works. `subtract` is unchanged.

```text
function add(a / b, c / d)
    if b = d then
        let n = a + c
        return n / b
    else if a = 0 then
        return c / d
    else if c = 0 then
        return a / b
    else if c = a then
        let n = a · (b + d)
        let m = b · d
        return n / m
    else if c = −a then
        let n = a · (d − b)
        let m = b · d
        return n / m
    else
        let n = a · d + c · b
        let m = b · d
        return n / m
    end if
end function
```

### 1.2 Multiplication

**Arithmetic.** Numerators multiply, and denominators multiply:

$$
\frac{a}{b} \cdot \frac{c}{d} = \frac{a \cdot c}{b \cdot d}.
$$

Both denominators are positive, so $b \cdot d$ is positive and the sign of the product ends up in the numerator, as the storage requires.

**Naive algorithm.** Two multiplications:

```text
function multiply(a / b, c / d)
    let n = a · c
    let m = b · d
    return n / m
end function
```

**The major shortcut: a cross match.** Suppose one value's numerator equals the other value's denominator, say $c = b$. Then the same number $b$ appears once on top and once on the bottom, and it cancels exactly:

$$
\frac{a}{b} \cdot \frac{b}{d} = \frac{a \cdot b}{b \cdot d} = \frac{a}{d}.
$$

The result is just the outer two stored numbers, $a$ over $d$, and no multiplication is done. The symmetric case, where the *first* value's numerator equals the *second* value's denominator ($a = d$), works the same way:

$$
\frac{a}{b} \cdot \frac{c}{a} = \frac{c}{b}.
$$

Signs need a moment's care. A denominator is always positive, but a numerator can be negative, so the match is really between magnitudes: a numerator of $-b$ also matches the denominator $b$. The magnitude cancels, and the leftover sign goes into the result's numerator:

$$
\frac{a}{b} \cdot \frac{-b}{d} = \frac{-a \cdot b}{b \cdot d} = \frac{-a}{d},
\qquad
\frac{-d}{b} \cdot \frac{c}{d} = \frac{-d \cdot c}{b \cdot d} = \frac{-c}{b}.
$$

The first is the case $c = -b$; the second is the symmetric case with a sign, $a = -d$.

A zero numerator causes no trouble: the matched numerator equals a positive denominator, so it is never zero, and if the *other* numerator is zero, the result $\frac{0}{d}$ is a correct zero.

*Worked example.* $\dfrac{2}{3} \cdot \dfrac{3}{5}$. The second numerator equals the first denominator ($3 = 3$), so the result is
$$
\frac{2}{5}.
$$
The naive path would need two multiplications; the shortcut needed none.

**Other shortcuts.** The most specific case is a pair of reciprocals, where both cross matches hold at once: $\frac{a}{b} \cdot \frac{b}{a} = 1$. In storage, the reciprocal of $\frac{a}{b}$ is $\frac{b}{a}$ when $a > 0$, and $\frac{-b}{-a}$ when $a < 0$ (the sign moves to the numerator so the denominator stays positive). Either way the product is $1$, returned as $\frac{1}{1}$. A zero factor is a minor shortcut: the product is zero, with no multiplication. A factor of one is another: if $a = b$, the first value is $1$ and the product is $\frac{c}{d}$; if $c = d$, the second value is $1$ and the product is $\frac{a}{b}$. Finally, a shared denominator, which was the big win for addition, gives **no saving** here: $\frac{a}{b} \cdot \frac{c}{b} = \frac{a \cdot c}{b \cdot b}$ still needs both multiplications, and the same is true of a shared numerator.

**All shortcuts for multiplication.** Inputs $a/b$ and $c/d$.

| Shortcut | Condition | Result | Saved |
|---|---|---|---|
| Reciprocals (most specific) | $c = b$ and $d = a$, or $c = -b$ and $d = -a$ | $\dfrac{1}{1}$ | both multiplications |
| Cross match (major) | $c = b$ | $\dfrac{a}{d}$ | both multiplications |
| Cross match, sign | $c = -b$ | $\dfrac{-a}{d}$ | both multiplications |
| Cross match, symmetric | $a = d$ | $\dfrac{c}{b}$ | both multiplications |
| Cross match, symmetric, sign | $a = -d$ | $\dfrac{-c}{b}$ | both multiplications |
| Zero factor | $a = 0$ or $c = 0$ | $\dfrac{0}{1}$ | both multiplications |
| Factor of one | $a = b$ | $\dfrac{c}{d}$ | both multiplications |
| Factor of one | $c = d$ | $\dfrac{a}{b}$ | both multiplications |
| Shared denominator | $b = d$ | $\dfrac{a \cdot c}{b \cdot b}$ | nothing: still two multiplications |
| None (naive) | always | $\dfrac{a \cdot c}{b \cdot d}$ | nothing |

**Algorithm with shortcuts.** Most specific first, then the major shortcut in its four forms, then the minor ones, then the naive path. The shared denominator gets no branch, since it saves nothing.

```text
function multiply(a / b, c / d)
    if (c = b and d = a) or (c = −b and d = −a) then
        return 1 / 1
    else if c = b then
        return a / d
    else if c = −b then
        return (−a) / d
    else if a = d then
        return c / b
    else if a = −d then
        return (−c) / b
    else if a = 0 or c = 0 then
        return 0 / 1
    else if a = b then
        return c / d
    else if c = d then
        return a / b
    else
        let n = a · c
        let m = b · d
        return n / m
    end if
end function
```

### 1.3 Division

**Arithmetic.** Dividing by $\frac{c}{d}$ is multiplying by its reciprocal $\frac{d}{c}$, which exists only when $c \neq 0$:

$$
\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c} = \frac{a \cdot d}{b \cdot c}, \qquad c \neq 0.
$$

**Structure.** The new denominator is $b \cdot c$, and $c$ may be negative. When it is, both new numbers are negated, which keeps the value the same and puts the sign back in the numerator: $\frac{n}{m} = \frac{-n}{-m}$.

**Naive algorithm.** Two multiplications, a check for division by zero first, and a sign fix last:

```text
function divide(a / b, c / d)
    if c = 0 then
        error "division by zero"
    end if
    let n = a · d
    let m = b · c
    if m < 0 then
        let n' = −n
        let m' = −m
        return n' / m'
    else
        return n / m
    end if
end function
```

**The major shortcut: a shared part cancels.** Division puts $a$ and $c$ on opposite sides of the fraction bar, and likewise $b$ and $d$: in $\frac{a \cdot d}{b \cdot c}$, the two numerators face each other, and so do the two denominators. So if the inputs share a numerator or share a denominator, that shared number cancels exactly, and no multiplication is needed. This is one idea with two forms:

$$
\text{shared numerator: } \frac{a}{b} \div \frac{a}{d} = \frac{a \cdot d}{b \cdot a} = \frac{d}{b},
\qquad
\text{shared denominator: } \frac{a}{b} \div \frac{c}{b} = \frac{a \cdot b}{b \cdot c} = \frac{a}{c}.
$$

Division by zero is still checked before either form. That check also protects the shared-numerator form: if $c = a$ and $c \neq 0$, then $a \neq 0$, so cancelling $a$ is allowed.

Signs again come down to magnitudes:

- *Shared numerator.* The two numerators can match in magnitude with opposite signs, $c = -a$. The magnitude cancels and leaves a factor $-1$: $\frac{a}{b} \div \frac{-a}{d} = \frac{-d}{b}$. With $c = a$ the result $\frac{d}{b}$ is positive, as it should be. Either way the denominator $b$ is positive, so the result is a valid stored value.
- *Shared denominator.* The denominators are positive, so they match exactly, but the result $\frac{a}{c}$ has the old numerator $c$ as its denominator, and $c$ may be negative. If $c < 0$, return $\frac{-a}{-c}$ instead, the same sign fix as the naive path.

*Worked example.* $\dfrac{2}{3} \div \dfrac{2}{7}$. The numerators match ($2 = 2$), so the result is the second denominator over the first:
$$
\frac{7}{3}.
$$
The naive path would need two multiplications; the shortcut needed none.

**Other shortcuts.** The most specific case is a value divided by itself: if $a = c$ and $b = d$ (and $c \neq 0$, already checked), the answer is $\frac{1}{1}$. Three minor shortcuts need no multiplication either. A zero dividend: if $a = 0$, the quotient is zero. Dividing by one: if $c = d$, the divisor is $1$ and the quotient is $\frac{a}{b}$. Dividing one: if $a = b$, the dividend is $1$ and the quotient is the reciprocal $\frac{d}{c}$, or $\frac{-d}{-c}$ when $c < 0$, the same sign fix as before.

**All shortcuts for division.** Inputs $a/b$ and $c/d$. The zero-divisor check always comes first and is an error, not a shortcut.

| Shortcut | Condition | Result | Saved |
|---|---|---|---|
| Division by zero (check, always first) | $c = 0$ | error | not applicable |
| Equal values (most specific) | $a = c$ and $b = d$ | $\dfrac{1}{1}$ | both multiplications |
| **Shared part cancels (major)** | | | |
| — shared numerator | $c = a$ | $\dfrac{d}{b}$ | both multiplications |
| — shared numerator, sign | $c = -a$ | $\dfrac{-d}{b}$ | both multiplications |
| — shared denominator | $b = d$ and $c > 0$ | $\dfrac{a}{c}$ | both multiplications |
| — shared denominator, sign | $b = d$ and $c < 0$ | $\dfrac{-a}{-c}$ | both multiplications |
| Zero dividend | $a = 0$ | $\dfrac{0}{1}$ | both multiplications |
| Dividing by one | $c = d$ | $\dfrac{a}{b}$ | both multiplications |
| Dividing one | $a = b$ and $c > 0$ | $\dfrac{d}{c}$ | both multiplications |
| Dividing one, sign | $a = b$ and $c < 0$ | $\dfrac{-d}{-c}$ | both multiplications |
| None (naive) | always | $\dfrac{a \cdot d}{b \cdot c}$, both negated if $b \cdot c < 0$ | nothing |

**Algorithm with shortcuts.** The zero-divisor check, then the most specific case, then the major shortcut in both forms, then the minor ones, then the naive path.

```text
function divide(a / b, c / d)
    if c = 0 then
        error "division by zero"
    else if a = c and b = d then
        return 1 / 1
    else if c = a then
        return d / b
    else if c = −a then
        return (−d) / b
    else if b = d and c > 0 then
        return a / c
    else if b = d then
        return (−a) / (−c)
    else if a = 0 then
        return 0 / 1
    else if c = d then
        return a / b
    else if a = b and c > 0 then
        return d / c
    else if a = b then
        return (−d) / (−c)
    else
        let n = a · d
        let m = b · c
        if m < 0 then
            let n' = −n
            let m' = −m
            return n' / m'
        else
            return n / m
        end if
    end if
end function
```
